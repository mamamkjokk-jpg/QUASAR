QUASAR-SHADOW — حزمة تنظيم طلبات المجموعات

ما الذي تضيفه؟
- طابورًا واحدًا لكل جلسة API لطلبات getThreadInfo و getThreadList.
- تمرير تغييرات الكنيات وأسماء المجموعات عبر الطابور نفسه.
- تسلسلًا يمنع تداخل طلبين على واجهة المجموعة نفسها.
- دمج الطلبات المتطابقة إذا كانت لا تزال معلّقة.
- فاصلًا أدنى بين الطلبات: قراءة المعلومات 1000ms، قراءة القوائم 1500ms، وتعديلات الكنيات/الأسماء 900ms.
- تهدئة تصاعدية عند أخطاء rate limit: 60 ثانية ثم 120 ثم 240 ثم 480 ثم حد أقصى 900 ثانية.
- اختبارات لا تتصل بفيسبوك ولا تشغّل البوت.

مهم:
- لا تغيّر الحزمة مؤقتات الفحص الدوري الموجودة في SHADOW/index.js.
- لا تعيد المحاولة تلقائيًا بعد فشل تعديل اسم أو كنية؛ الخطأ يرجع للملف المستدعي، ويُترك الطابور ليتابع بعد التهدئة عند rate limit.
- الحزمة لا تشغّل البوت.
- مثبت الحزمة يوقف إذا لم يتعرّف على نقاط الربط المتوقعة، ولا يكتب فوق ملفاتك عند الفشل.

طريقة التثبيت في Termux:
1) ضع ZIP في مجلد مشروع QUASAR.
2) استخرج محتويات ZIP إلى مجلد المشروع، وليس إلى مجلد SHADOW فقط.
3) نفّذ:
   cd ~/QUASAR || exit 1
   node apply-rate-control.js
   node --check SHADOW/index.js
   node --test SHADOW/tests/thread-operation-queue.test.js

المثبت ينشئ نسخة احتياطية من الملفات التي سيغيّرها داخل:
backups/thread-operation-guard-...

لا تشغّل البوت قبل مراجعة نتيجة الاختبارات.
